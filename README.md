## About me

I'm **Kamil Król**, an independent developer based in Poland and the founder of **KP_Code Digital System**.

I design and develop websites, web applications, and digital tools that combine clear interfaces with maintainable code. I focus on practical solutions, continuous learning, and a development process where quality matters at every stage.

## What I build

**KP_Code Digital Studio**  
Modern websites and tailored web solutions, built around usability, accessibility, responsive design, and reliable implementation.

**KP_Code Digital Vault**  
Digital products, educational resources, and practical tools designed to make everyday tasks and learning more effective.

**Software & SaaS**  
Web applications, dashboards, and product concepts focused on useful functionality and intuitive user experiences.

## Technologies & tools

- **Frontend:** HTML5 · CSS3 · JavaScript (ES Modules) · Bootstrap
- **Development & QA:** Git · GitHub · Vite · Playwright
- **Design & prototyping:** Figma
- **Currently exploring:** TypeScript · CAD modeling

## Engineering principles

- **Accessibility first** — semantic HTML, keyboard support, and inclusive interfaces
- **Responsive by design** — mobile-first layouts and adaptable components
- **Quality in practice** — testing, performance, and careful verification
- **Maintainable foundations** — readable code, reusable patterns, and clear documentation

## How I work

I approach development through focused, incremental improvements: understand the problem, build a solid foundation, test the outcome, and refine the details.

For me, good software is not just about how it looks — it's about how reliably it works and how well it serves the people using it.
